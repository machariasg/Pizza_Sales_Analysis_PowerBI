Pizza Sales Analysis Dashboard

Project Overview

This project analyzes pizza sales data using Microsoft Power BI to explore sales performance and identify useful business insights.

Tools Used

Microsoft Power BI

DAX (Data Analysis Expressions)

Data visualization and reporting

Project Objectives

Analyze overall pizza sales performance.

Compare sales across pizza categories and products.

Identify trends and patterns in sales data.

Present key performance indicators through an interactive dashboard.

Dashboard

The Power BI report is available in the file Pizza_Sales_Analysis.pbix in this repository.
